# Vuli: приложение-самоучитель языков

Продукт: Vuli (vulilang.com). Первый язык: турецкий, интерфейс на русском. Владелец проекта не программист: объясняй простыми словами, по-русски.

## Где контекст
Документация и прототип лежат в репозитории hello-world2 (ветка `claude/wonderful-einstein-6a6c4s`), на сервере в `~/vuli-docs`. Прочитай по порядку:
1. `docs/00-start-here.md`
2. `docs/02-decisions.md` (источник правды по решениям)
3. `docs/07-site-build-brief.md` (архитектура и цели фазы 1)
4. `docs/09-server-and-claude-code-setup.md` (сервер и безопасность)
5. `docs/10-tasks.md` (задачи по порядку)
6. `prototype/lessons-1-2.html` (дизайн и логика уроков 1–2)

## Правила
- Работай по задачам из `docs/10-tasks.md`: одна задача за раз. После задачи: обнови `docs/02-decisions.md`, отметь задачу, сделай коммит с понятным сообщением.
- Не используй видео и фрагменты из сериалов. Не добавляй игровые механики, которые пользователь не поймёт без объяснений.
- Секреты (пароли, ключи) только в `.env` на сервере и секретах GitHub. Не коммить, не печатай в чат.
- Запускай команды, меняющие сервер, только объяснив владельцу, что и зачем. Не работай от root. Не отключай запросы разрешений.
- Pull request создавай только когда владелец попросит.
- Примеры на турецком подготовлены ИИ: помечай «требует проверки носителем» в контенте.

## Стек
TypeScript, Next.js (App Router), Tailwind, PostgreSQL, Drizzle, Docker Compose + Caddy, Resend для писем, FSRS для повторения. Общая логика в `packages/core`. API версионируем (`/api/v1`).

## Команды (заполни после T01)
`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
