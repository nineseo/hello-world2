# Проект: приложение-самоучитель языков

Этот репозиторий содержит документацию и прототип приложения для изучения языков (первый язык: турецкий, интерфейс на русском). Код старого шаблона в корне (`src`, `package.json` и др.) не относится к продукту.

Перед работой прочитай `docs/00-start-here.md` и `docs/02-decisions.md`: там цель, принятые решения и текущие задачи. Отвечай пользователю по-русски. Не добавляй в продукт видео и фрагменты из сериалов. Не предлагай механики, которые пользователь не поймёт без объяснений.
