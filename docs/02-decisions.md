## Решено

| Тема | Решение |
|---|---|
| Целевая аудитория | Взрослые, 3 группы: новичок (с нуля), продвинутый, «почти смотрю сериалы без субтитров». **Начинаем с новичка**, но структура должна позволять добавить остальные (входной тест, пропуск уроков). |
| Обещания по уровню | Пока не даём. Сначала каркас (движок), потом наполнение и тесты. |

| Команда | Владелец + помощница (турецкий ~A1) + Claude + DeepSeek. Носитель пока не привлекается. |
| Название | Короткое, брендовое, **не привязано к турецкому** (будут другие языки). Пока не выбрано. |
| Прогресс | Не показывать прогресс только как «A1 → A2». Нужна мелкая шкала внутри уровней. |
| Закрытая версия | Доступ только у администраторов, без системы приглашений. |
| Выбор уровня | Пользователь выбирает сам; тест — только опционально («Помоги определить»), не обязателен. |

## Предложения (ждут подтверждения)

1. **Новый отдельный проект и репозиторий**, не внутри dizisub. Причины: чистая юридическая граница, свободная архитектура, не тащим наследие.
2. **Рабочее кодовое имя** вместо названия; закрытый стенд на временном адресе (админ-доступ). Домен — когда выберем название.
3. **Прогресс в нескольких слоях**: путь из небольших «станций», процент покрытия реальной речи (по частотным данным), милистоуны «теперь ты понимаешь…». CEFR — только как мелкая справочная метка.
4. **Монетизация**: не принимаем сейчас. Движок строим с «правами доступа» (entitlements), чтобы переключаться между моделями без переделки. Предварительно: без рекламы в уроках, free = часть курса + дневной лимит, подписка = всё.
