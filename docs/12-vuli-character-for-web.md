# Персонаж Vuli: как подключить к веб-версии (задание для Claude Code)

Решение владельца: талисман продукта — белый пушистый щенок самоеда Vuli (бледно-розовый шарф, синий жетон с буквой V). Образ утверждён, картинки сгенерированы внешним инструментом, переделывать их не нужно. Жёлтый «кружок-талисман» из старого прототипа больше не используется.

## 1. Файлы (в архиве: `prototype/assets/vuli/`)
| Файл | Что это |
|---|---|
| `happy.webp`, `think.webp`, `sad.webp`, `cheer.webp` | 4 позы на прозрачном фоне, высота 300 px (для интерфейса) |
| `*@2x.webp`, `*.png` | те же позы в полном размере (≈320×450 px) для крупных мест и retina |
| `icon.png`, `icon-512.png`, `icon-192.png`, `icon-48.png` | иконка со скруглением и прозрачными углами (для favicon, PWA, превью) |
| `vuli-animation.css` | анимации (CSS) |
| `vuli-blink-overlay.svg` | слой «закрытые глаза» для позы happy (viewBox 0 0 318 453) |
| `layers-source.png` | исходник для справки, в продукт не включать |

Положи их в `apps/web/public/vuli/`. Контент не менять и не «улучшать»: не перерисовывать, не заменять другой собакой.

## 2. Позы и где используются
- **happy**: приветствие, верный ответ, профиль, главная вкладка «Учиться», «С возвращением».
- **think**: подсказка, «ты знаешь это слово?», задание на понимание (в прототипе пока не использована).
- **sad**: неверный ответ («Почти!»), ошибки без наказания. Тон дружелюбный, не «ругает».
- **cheer**: урок пройден, цель дня выполнена (экран завершения).
Правило: не больше одного Vuli на экране, кроме списков сообщений (там маленькие аватарки).

## 3. Компонент
Сделай React-компонент `<Vuli mood="happy|think|sad|cheer" size={64} />` в `apps/web/components/Vuli.tsx`:
- `mood="happy"` собирается из трёх слоёв внутри обёртки `span.vwrap.vuli.vuli-happy` с явной шириной `size*318/453` и высотой `size`: основа (img), слой хвоста (тот же img с классом `vtail`, обрезан через `clip-path`), слой глаз (`svg.vblink`, содержимое из `vuli-blink-overlay.svg`).
- остальные позы: один `<img class="vuli vuli-{mood}">`, высота `size`, ширина авто.
- `alt="Vuli"` у основной картинки, у слоёв `alt="" aria-hidden`.
- Образец рабочей разметки и стилей: функция `mascot()` в `prototype/lessons-1-2.html` и `prototype/assets/vuli/vuli-animation.css`.
- Анимацию отключать при `prefers-reduced-motion` (уже есть в css).
- Используй `next/image` с `unoptimized` или обычный `<img>` для webp; ширину задавай явно, чтобы не было схлопывания (в прототипе так уже исправлялась ошибка: без явной ширины Vuli пропадал).
- Для размеров до 120 px бери `*.webp`, для больших `*@2x.webp`.

## 4. Куда поставить (как в прототипе)
1. Экран выбора уровня: Vuli (happy, ~120 px) в правом верхнем углу.
2. Главная вкладка «Учиться»: Vuli (happy, ~92 px) справа в верхней строке, рядом с «дней подряд» и XP; он слегка заходит на верхнюю карточку главы.
3. Панель результата в уроке: happy (верно), sad (неверно), ~54 px.
4. Профиль: happy ~64 px.
5. Окно «С возвращением!»: happy ~72 px.
6. Экран завершения урока: cheer ~150 px.
7. Favicon, apple-touch-icon, manifest PWA: `icon-48/192/512.png`.

## 5. Проверка
- Скриншоты в светлой и тёмной теме на телефоне и десктопе, Vuli виден на всех перечисленных экранах.
- Лёгкая страница: общий вес картинок на экране не больше ~100 КБ (используй webp).
- Не используй видео и фрагменты из сериалов (общее правило продукта).

## 6. Известные ограничения (записать в docs/02-decisions.md, не чинить без владельца)
- Анимация поза-«радуется» собрана из одной картинки; при размере больше ~200 px вокруг закрытого глаза может быть заметна светлая «заплатка». Для публичной версии планируется настоящая анимация (Rive/Lottie) от художника.
- Иконка для магазинов приложений должна быть квадратом без скруглений и каймы; текущая `icon.png` годится только для веба.
