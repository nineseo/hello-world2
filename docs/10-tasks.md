# Задачи фазы 1 (по порядку)

Правила: выполняй по одной задаче; в конце каждой обнови `docs/02-decisions.md`, отметь статус здесь (`[x]`) и сделай коммит. Если что-то неясно, задай вопрос владельцу простыми словами.

## T01. Каркас репозитория
- Монорепозиторий: `apps/web` (Next.js + Tailwind), `packages/core` (TypeScript), `content/`, `docs/`.
- Линтер, проверка типов, тесты (Vitest), скрипты `lint`, `typecheck`, `test`, `build`.
- `.gitignore` (включая `.env*`), `.env.example` без секретов.
- Готово, когда: `npm run lint && npm run typecheck && npm test && npm run build` проходят.
- [ ] выполнено

## T02. CI на GitHub
- GitHub Actions: lint, typecheck, test, build на каждый push и pull request.
- Готово, когда: пустой коммит проходит зелёную проверку.
- [ ] выполнено

- Сервер подготовлен скриптом `server/bootstrap-server.sh` (в репозитории hello-world2).
- Готово, когда: `https://staging.vulilang.com` открывает страницу «Vuli, скоро» с валидным сертификатом.
