# Таблица приложений: плюсы, минусы, что берём и делаем лучше

✓ — приложение проверялось поиском в октябре 2026 (см. `04-competitor-check.md`). Остальное — моё знание и отзывы, требует проверки.

| Приложение | Плюсы | Минусы | Что берём и как делаем лучше |
|---|---|---|---|
| **Duolingo** ✓ | Стрики, заморозка серии, напоминания, короткие занятия, ощущение прогресса, бесплатный старт | Поверхностная грамматика, «неестественные» ИИ-фразы, сердца и платная стена, давление уведомлений, очень длинный путь | Берём цикл привычки. Делаем лучше: настоящие объяснения, без сердец и давления, реальные реплики вместо абсурдных фраз |
| **Babbel** ✓ | Уроки 10–15 мин, повторение в начале урока, грамматика короткими вставками, отдельный справочник, диалоги от лингвистов | Слабое говорение, дорого, мало продвинутого | Берём повтор в начале и справочник. Делаем лучше: жёсткая спираль и сквозные примеры между уроками |
| **Busuu** ✓ | Курс по уровням, проверка письма носителями, офлайн | Скучный интерфейс, цена | Берём офлайн. Делаем лучше: живая подача и мелкие шаги прогресса |
| **Mondly** ✓ | Красивый интерфейс, чат-бот, уроки 10–15 мин | Слабая грамматика, один путь для начинающих и продвинутых, повторяющиеся упражнения | Берём приятный вид и диалоги. Делаем лучше: выбор уровня и пропуск станций, грамматика через открытие |
| **Memrise** ✓ | Видео носителей, интервальное повторение, мнемоники | Неровное качество курсов, часть контента платная | Берём видео-подход. Делаем лучше: единый путь вместо разрозненных курсов |
| **Rosetta Stone** | Погружение, акцент на произношении | Дорого, медленно, нет объяснений | Берём упор на произношение. Делаем лучше: объясняем «почему так» |
| **Pimsleur** ✓ | Аудио-метод, учишь на ходу, заставляет говорить | Нет письма и чтения, дорого, однообразно | Берём аудио-режим в будущем. Делаем лучше: связка слух, чтение и говорение |
| **Michel Thomas** | Ощущение «я это понимаю» с первых минут, без зубрёжки | Только аудио, узкий выбор языков | Берём принцип «сначала понимание». Делаем лучше: то же в интерактивном виде |
| **LingoDeer** | Настоящие грамматические объяснения | Узкий выбор языков, сухо | Берём глубину объяснений. Делаем лучше: подача интереснее |
| **Drops** | Красивые 5-минутные сессии, картинки | Только слова, нет грамматики, лимит времени | Берём визуальную лёгкость. Делаем лучше: слова всегда в предложениях и связаны с грамматикой |
| **Anki** | Мощное повторение, гибкость | Ужасный интерфейс для новичка, нужно самому делать колоды | Берём алгоритм повторения (FSRS). Делаем лучше: повторение встроено и невидимо |
| **Clozemaster** | Слова в предложениях с пропусками | Нет системы обучения | Берём упражнения с пропусками. Делаем лучше: путь, а не набор тренажёров |
| **LingQ** | Чтение и слушание реального контента, словарь пользователя | Сложный интерфейс, нет пути с нуля | Берём «тап по слову» и личный словарь. Делаем лучше: ведём с нуля |
| **Lingopie** ✓ | Сериалы, интерактивные субтитры, авто-карточки из сцен, уже есть турецкий | Не курс, сложно новичкам, мало грамматики | Главный конкурент по идее. Берём «карточки из сцен». Делаем лучше: структурированный путь новичка к сериалам |
| **FluentU, Language Reactor, Yabla** | Реальные видео с интерактивными субтитрами | Инструменты, а не курс; устаревший интерфейс | Берём интерактивные субтитры. Делаем лучше: уроки вокруг сцен |
| **Speak, Praktika (ИИ-репетиторы)** ✓ | Говорение без страха ошибиться, роль-плей | Поверхностная обратная связь, дорого, нет структуры | Берём говорение. Делаем лучше: ИИ-диалог только в рамках изученных слов |
| **Репетиторы (italki, Preply)** | Живое общение и мотивация | Дорого, нет единой программы, нужен график | Заменяем регулярную практику; живой человек остаётся опцией |
| **Lingualeo, Puzzle English (РФ)** | Привычны русскому пользователю, обучение через видео (Puzzle English) | Неровное качество контента, в основном английский | Берём привычный подход. Делаем лучше: полноценный курс турецкого |
| **Приложения для турецкого** ✓ | Фокус на языке (TurkishFluent, Ling и др.) | Малые команды, нет современного самоучителя на русском | Первыми занимаем эту нишу |
