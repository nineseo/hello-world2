# Что делает владелец (по шагам, без программирования)

Цель: к началу новой сессии у вас есть репозиторий, аккаунты хостинга и базы данных, а домен готов.

## Шаг 1. Защитить домен (10 минут)
1. На Internet.bs: **Мой аккаунт → Account Security** → включите двухфакторную защиту.
2. Проверьте способ оплаты и включите автопродление домена vulilang.com.
3. Убедитесь, что включён бесплатный анонимный WHOIS (скрывает ваши данные).
4. Включите бесплатную переадресацию почты: `hello@vulilang.com` → ваш Gmail (в разделе домена найдите «Email переадресация»).

## Шаг 2. Создать репозиторий на GitHub (5 минут)
1. На github.com: **New repository**. Имя: `vuli`. Владелец: тот же аккаунт (nineseo). Доступ: **Private**.
2. Добавьте файл README (галочка «Add a README file»).
3. Убедитесь, что приложение Claude для GitHub имеет доступ к этому репозиторию: github.com/apps/claude/installations/select_target → Configure → выберите `vuli`.

## Шаг 3. Подготовить свой сервер (хостинг)
Сначала нужно узнать, какой у вас хостинг. Напишите Claude (или выпишите себе):
1. Провайдер и страна сервера.
2. Тип: **VPS/VDS или выделенный сервер с root-доступом** (подходит) или обычный хостинг с панелью cPanel/ISPmanager для сайтов (для нашего стека не подходит).
3. Система (лучше Ubuntu 24.04 LTS), объём памяти (лучше 4 ГБ), диск (от 40 ГБ).
4. Есть ли у сервера IP-адрес (запишите его).
Пароль root и ключи в чат не отправляйте. Claude даст пошаговый скрипт настройки, который вы вставите в консоль сервера, и скажет, куда добавить ключ для выкладки (в секреты репозитория GitHub).

На Internet.bs в DNS домена позже понадобится добавить записи (Claude подскажет): `staging` → IP сервера, а позже `@` и `www`.

## Шаг 4. Новая сессия Claude
1. Откройте claude.ai/code → **Новая сессия** → выберите репозиторий `nineseo/vuli`.
2. Вставьте сообщение из раздела «Первое сообщение» ниже.
3. В новой сессии Claude скажет, что нужно сделать с доменом и ключами. Ключи добавляются в настройки окружения сессии или в панель Vercel, не в чат.

## Первое сообщение для новой сессии

```
Привет! Мы строим приложение-самоучитель языков Vuli (первый язык: турецкий, интерфейс на русском). Домен: vulilang.com.

Документация и прототип лежат в другом репозитории: nineseo/hello-world2 (ветка claude/wonderful-einstein-6a6c4s). Добавь его в сессию (только чтение) и прочитай: docs/00-start-here.md, docs/02-decisions.md, docs/03-course-skeleton.md, docs/06-v1-scope-for-review.md, docs/07-site-build-brief.md и prototype/lessons-1-2.html (дизайн и логика одобрены).

Новый код пиши в репозитории nineseo/vuli. Задача фазы 1 описана в docs/07-site-build-brief.md: закрытая веб-версия на staging.vulilang.com для администраторов.

Начни с короткого плана и вопросов ко мне, если нужны решения. Я не программист, объясняй простыми словами. Не проси меня вставлять пароли и ключи в чат: скажи, куда их добавить. Pull request создавай только когда я попрошу.
```

Если новая сессия не может добавить hello-world2, скачайте папку `docs/` и `prototype/` из этого репозитория и приложите файлами.

## Шаг 5. Параллельно (можно позже)
- Доступ к данным dizisub (слова, идиомы, грамматика): нужен для следующей фазы.
- Консультация юриста по знаку Vuli.
- Решить, какая собака (выбор образа), когда доберётесь до дизайна лендинга.

## Примерные расходы (проверьте актуальные цены)
- Домен: около €12 в год (уже оплачено).
- Supabase и Vercel: на старте бесплатные тарифы. Для публичного коммерческого сайта Vercel потребует платный тариф (порядка $20 в месяц).
- Для магазинов приложений: Apple Developer около $99 в год, Google Play единоразово около $25.
