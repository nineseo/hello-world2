# Что делает владелец (кратко)

Подробные шаги: `docs/09-server-and-claude-code-setup.md`.

1. **Защитить домен** на Internet.bs: двухфакторная защита, автопродление, анонимный WHOIS, переадресация почты `hello@vulilang.com` на ваш Gmail.
2. **Заказать сервер:** VPS Ubuntu 24.04, 4 ГБ, 40 ГБ; написать провайдера и страну (от страны зависит закон о хранении данных).
3. **Ключ SSH** на вашем компьютере (`ssh-keygen -t ed25519`).
4. **Загрузить архив** `vuli-handoff.zip` на сервер и запустить `server/bootstrap-server.sh` (выбрать режим SSH).
5. **DNS:** запись A `staging` → IP сервера.
6. **Установить Claude Code** под пользователем `vuli` и вставить первое сообщение из раздела 4 (шаг 8) файла 09.
7. **Параллельно:** данные dizisub, консультация юриста по знаку Vuli, выбор собаки.

Расходы: домен около €12 в год (оплачено); сервер по цене провайдера; письма через Resend, бесплатные лимиты на старте (проверьте).
